# Simranjot Professional Portfolio

A responsive, modern recruiter-focused portfolio built with vanilla HTML, CSS and JavaScript.

## Functional features
- Responsive navigation + mobile menu
- Light/dark theme toggle with localStorage
- Project category filters
- Working project case-study modals
- Copy-email buttons
- Resume links
- GitHub / LinkedIn / email links
- Hover states and micro-interactions
- Scroll-reveal animations
- Accessible buttons and labels
- SEO metadata

## Run locally
```bash
python -m http.server 5500
```
Open http://localhost:5500
